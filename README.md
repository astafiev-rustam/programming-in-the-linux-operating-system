# Лекция №1: Введение в экосистему Linux. Работа с командной оболочкой

## Экосистема Linux

Linux - это не просто операционная система, это воплощение набора идей, сформулированных еще в 70-х годах создателями Unix. Понимание этих идей - ключ к эффективной работе.

**Правило 1: Каждая программа делает одну вещь, и делает её хорошо.**

Это противоположность подходу «монолитных» программ, которые пытаются быть всем для всех. Например, есть отдельная программа `grep` для поиска текста, `wc` для подсчета слов и строк, `sort` для сортировки. Они отлично делают свою одну задачу.

**Правило 2: Предполагайте, что вывод программы станет входом для другой.**

Программы должны быть спроектированы так, чтобы они могли легко взаимодействовать. Это приводит нас к одному из главных механизмов данной операционной системы: **конвейеры**.

**Конвейер** - это способ соединить вывод одной программы (`stdout`) со входом другой (`stdin`).

**Пример:** `cat log.txt | grep "error" | sort | uniq -c`
        *   `cat` читает файл и выводит его содержимое.
        *   `grep` принимает этот вывод и фильтрует его, оставляя только строки с "error".
        *   `sort` сортирует эти строки по алфавиту.
        *   `uniq -c` удаляет повторяющиеся строки и показывает количество их вхождений.

**Правило 3: "Все есть файл"**

Это, пожалуй, самый важный принцип. В Linux файлами представлены не только документы на диске. **Обычные файлы:** ваши документы, программы. **Каталоги (директории):** тоже файлы, содержащие списки других файлов. **Устройства:** жесткий диск (`/dev/sda`), USB-флашка (`/dev/sdb1`), клавиатура, мышь — все это файлы в директории `/dev`. Читая и записывая в них, вы взаимодействуете с устройством. **Процессы:** информация о запущенных процессах представлена в виде файлов в виртуальной файловой системе `/proc`.

## Базовая структура файловой системы

В Linux нет дисков `C:` и `D:`. Вся файловая система представляет собой единое дерево, корень которого обозначается символом `/`. Важные ветки этого дерева стандартизированы (Filesystem Hierarchy Standard — FHS).

`/bin` — основные исполняемые файлы (бинарники), необходимые для загрузки и работы в single-user mode (например, `ls`, `cat`, `bash`).

`/etc` — **конфигурационные файлы** всей системы. Здесь лежат настройки ваших программ, сервисов, сети. Это текстовые файлы! Важный каталог для администрирования.

`/home` — домашние каталоги пользователей. Здесь хранятся ваши личные файлы, настройки, рабочие столы. Для каждого пользователя — своя папка (например, `/home/student`).

`/usr` — **user software resources**. Вторичная иерархия для данных пользователя. Содержит большинство устанавливаемых программ (`/usr/bin`), библиотеки (`/usr/lib`), документацию (`/usr/share/doc`).

`/var` — **variable data**. Файлы, которые меняются в процессе работы системы: логи (`/var/log`), кэши, очереди почты.

`/tmp` — временные файлы, удаляемые при перезагрузке.

`/proc` и `/sys` — **виртуальные файловые системы**, предоставляющие доступ к информации о **процессах** и **ядре** системы соответственно. Они не лежат на диске, а создаются ядром на лету.

## Подготовка к установке ОС
В рамках занятий по дисциплине нами будет использоваться образ операционной системы, который будет запущен на средствах виртуализации. Например, в качестве средства виртуализации можно использовать **Virtual Box**. Ссылка на страницу скачивания:

https://www.virtualbox.org/wiki/Downloads

В качестве образа операционной системы возьмём следующий с официального сайта ГК Астра:

https://dl.astralinux.ru/astra/stable/2.12_x86-64/iso/

После успешного скачивания перейдём непосредственно к установке.

## Пошаговая настройка и установка ОС
Отлично! Вот максимально подробная пошаговая инструкция по установке и настройке ОС Astra Linux Common Edition в среде виртуализации VirtualBox, составленная в запрошенном формате.

---

### **Этап 1. Создание виртуальной машины.**

**Шаг 1.1. Создайте новую виртуальную машину.**
В главном окне VirtualBox нажмите кнопку **"Создать"**. Заполните параметры:
*   **Имя:** `Astra Linux`. *Имя поможет вам идентифицировать машину*.
*   **Папка машины:** Оставьте по умолчанию или выберите нужный путь.
*   **Тип:** `Linux`.
*   **Версия:** `Debian (64-bit)` или `Other Linux (64-bit)`. *Astra Linux основана на Debian, поэтому этот выбор наиболее корректен.*

**Шаг 1.2. Настройте объем оперативной памяти (ОЗУ).**

*Выделите не менее 2048 МБ (2 ГБ). Для комфортной работы с графическим интерфейсом рекомендуется 4096 МБ (4 ГБ), если ресурсы вашего физического компьютера позволяют это сделать. Не выделяйте больше половины от общего объема вашей физической ОЗУ.*

**Шаг 1.3. Создайте виртуальный жесткий диск.**
*   Выберите "Создать новый виртуальный жесткий диск".
*   **Тип файла:** `VDI (VirtualBox Disk Image)`.
*   **Формат хранения:** `Динамический виртуальный жесткий диск`. *Это означает, что файл диска на вашем реальном HDD/SSD будет занимать мало места initially и будет увеличиваться по мере заполнения данными внутри виртуальной машины, вплоть до указанного вами предела.*
*   **Размер:** Установите не менее 25-30 ГБ. *Это виртуальный "раздел" для вашей Astra Linux, куда будет установлена система, пользовательские файлы и программы.*

---

### **Этап 2. Настройка аппаратной части виртуальной машины.**

**Шаг 2.1. Включите 2D-ускорение для видео.**
Выберите созданную машину и нажмите "Настроить". Перейдите в раздел **"Дисплей"**.
*   **Видеопамять:** Установите не менее 128 МБ.
*   **Включить 2D-ускорение:** Отметьте галочку. *Этот пункт значительно улучшит производительность графического интерфейса (Fly Desktop), сделав работу с окнами более плавной.*

**Шаг 2.2. Подключите загрузочный ISO-образ.**
Перейдите в раздел **"Носители"**. В дереве контроллера носителей выберите "Пусто". Справа, нажмите на иконку диска и выберите "Выбрать образ оптического диска...". Укажите путь к скачанному ранее файлу `*.iso` с дистрибутивом Astra Linux.

*Это эмулирует вставку загрузочного DVD-диска в виртуальный привод вашей машины, что позволит вам загрузиться с него и начать установку.*

**Шаг 2.3. (Рекомендуется) Включите общий буфер обмена и Drag&Drop.**
Перейдите в раздел **"Общие папки"**.

Установите для обоих параметров ("Общий буфер обмена" и "Drag'n'Drop") значение "Двунаправленный". *Эта настройка позволит вам легко копировать текст и файлы между вашей основной ОС и виртуальной машиной после установки гостевых дополнений.*

---

### **Этап 3. Установка операционной системы.**

**Шаг 3.1. Запустите виртуальную машину и начните установку.**
Нажмите кнопку "Запуск". Через несколько секунд вы увидите меню загрузки.
Выберите первый пункт (или просто дождитесь окончания отсчета таймера): **"Установка Astra Linux Common Edition"**. *Это запустит графический установщик на основе Debian-Installer.*

**Шаг 3.2. Выберите язык и раскладку.**
Последовательно выберите язык интерфейса, страну и локализацию. Для русскоязычного пользователя обычно выбирают: `Русский` -> `Россия` -> `Русская` (раскладка клавиатуры). *Установщик проверит наличие компонентов и загрузит в оперативную память необходимые для установки файлы.*

**Шаг 3.3. Настройте сеть.**
Введите сетевое имя (hostname) для вашей машины, например, `astra-vm`. Имя домена можно оставить пустым. *Hostname — это сетевое имя компьютера, которое будет использоваться для его идентификации в локальной сети.*

**Шаг 3.4. Создайте учетную запись основного пользователя.**
Введите ваше имя, имя пользователя (логин) и пароль. Обязательно запомните или запишите логин и пароль! *В Astra Linux, в отличие от некоторых других дистрибутивов, этот пользователь по умолчанию не обладает административными правами (root). Для выполнения привилегированных действий используется механизм `sudo`.*

**Шаг 3.5. Настройте часовой пояс.**
Выберите ваш регион и часовой пояс (например, `Москва`). *Это важно для корректного отображения времени и работы планировщика задач.*

**Шаг 3.6. Настройте разметку диска.**
Это критически важный шаг. Для простоты и большинства учебных/тестовых задач выберите вариант: **"Всё на одном разделе"**. *Это автоматически создаст единственный раздел под корневую директорию (`/`) и раздел подкачки (swap). Для продвинутых сценариев (например, отдельный раздел для `/home`) можно выбрать ручной метод.*

**Шаг 3.7. Подтвердите запись изменений на диск.**
Установщик покажет сводку по разметке. Нажмите "Да" и "Продолжить", чтобы начать физическую (в рамках виртуального диска) запись разметки и копирование системных файлов. *Это необратимый шаг внутри виртуальной среды, но так как вы работаете с виртуальным диском, вы можете в любой момент создать новую машину.*

**Шаг 3.8. Настройте менеджер пакетов (`apt`).**
На вопрос об использовании сетевого зеркала архива ответьте "Нет". *Поскольку у вас уже есть полный установочный образ, и для базовой настройки сети не требуется, нет необходимости скачивать пакеты из интернета на этом этапе.*

**Шаг 3.9. Настройте политику безопасности (PAM).**
Вам будет предложено установить пароль для администратора (`root`). В Astra Linux это **обязательный** шаг. Задайте надежный пароль. *Пароль root требуется для входа в однопользовательском режиме, для обслуживания системы и для некоторых компонентов подсистемы безопасности. Это одна из особенностей, отличающих Astra Linux от более "пользовательских" дистрибутивов.*

Далее, настройте пароль для пользователя `root` по умолчанию.

**Шаг 3.10. Установите загрузчик GRUB.**
Подтвердите установку загрузчика GRUB в главную загрузочную запись (MBR) вашего виртуального диска (обычно `/dev/sda`). *GRUB необходим для загрузки операционной системы при включении виртуальной машины.*

**Шаг 3.11. Завершите установку.**
После копирования всех файлов и настройки загрузчика система предложит вам завершить установку. Нажмите "Продолжить". Виртуальная машина перезагрузится. **Важно:** После перезагрузки зайдите в настройки виртуальной машины ("Носители") и отключите загрузочный ISO-образ, чтобы машина загрузилась с только что установленного виртуального жесткого диска.

---

### **Этап 4. Первоначальная настройка и начало работы.**

**Шаг 4.1. Войдите в систему.**
После загрузки вы увидите графический экран входа (менеджер входа Fly-DM). Выберите созданного вами пользователя и введите его пароль. *Вы попадете в рабочий стол Fly (основанный на Enlightenment) — стандартное графическое окружение Astra Linux Common Edition.*

**Шаг 4.2. (Важно!) Обновите систему.**
Откройте терминал (через меню приложений или сочетание клавиш, например, `Ctrl+Alt+T`). Выполните команды:
    ```bash
    su -
    ```
    *Введите пароль пользователя `root`, который вы задавали на шаге 3.9. Команда `su -` позволяет получить полномочия администратора, сменив пользователя на root.*
    ```bash
    apt update
    apt upgrade
    ```
    *Команда `apt update` обновляет список доступных пакетов из репозиториев, а `apt upgrade` устанавливает все доступные обновления для уже установленных пакетов. Это критически важно для безопасности и стабильности системы.*

**Шаг 4.3. Установите Пакет гостевой ОС (Guest Additions).**
Этот шаг сделает работу с виртуальной машиной гораздо удобнее.
1.  В меню VirtualBox выберите: `Устройства -> Подключить образ диска Дополнений гостевой ОС...`.
2.  Внутри виртуальной машины откроется виртуальный CD-диск.
3.  В терминале (с правами root, `su -`) выполните:
    ```bash
    apt install build-essential dkms linux-headers-$(uname -r)
    mkdir -p /mnt/cdrom
    mount /dev/cdrom /mnt/cdrom
    cd /mnt/cdrom
    ./VBoxLinuxAdditions.run
    ```
*Этот набор команд устанавливает компилятор и заголовки ядра, необходимые для сборки модулей, а затем запускает скрипт установки гостевых дополнений. После перезагрузки вы получите корректное разрешение экрана, поддержку общего буфера обмена, Drag&Drop и общих папок.*

Поздравляю! Теперь у вас полностью настроенная и готовая к работе виртуальная среда Astra Linux. Вы можете приступать к изучению системы, установке дополнительного ПО (через менеджер пакетов `apt` или центр управления "Центр управления Fly") и её настройке под ваши задачи.
