# Методические указания по дисциплине

Дисциплина готовит разработчиков для работы в среде Linux, объединяя навыки системного администрирования и создания программного обеспечения. Студенты изучат управление процессами, пакетами и сетями, а также освоят полный цикл разработки — от компиляции и отладки до создания собственных библиотек и дистрибутивных пакетов.
